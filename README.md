# 🎭 Escénika

Plataforma de booking artístico sin comisiones.

## 🚀 Inicio Rápido

```bash
npm install
npm run dev
```

## 🛠️ Stack

- React 19 + TypeScript
- TanStack Start (SSR)
- Tailwind CSS + shadcn/ui
- Supabase + Stripe
- Vercel
